- ## 🔌 API Endpoints

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/api/v1/expenses` | Fetch all logged expenses |
| `POST` | `/api/v1/expenses` | Add a new expense record |
| `GET` | `/api/v1/expenses/{id}` | Get details of a single expense |
| `PUT` | `/api/v1/expenses/{id}` | Update an existing expense record |
| `DELETE` | `/api/v1/expenses/{id}` | Delete an expense record |

cd <repo-name>

### 2. Create and activate a Virtual Environment
